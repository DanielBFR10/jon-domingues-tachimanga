# Roteiro de validação

## Catálogo e agrupamento

- [ ] O catálogo lista séries por arquivo canônico, sem transformar categorias-pai em séries.
- [ ] Não criar uma série agregada chamada Batman, Universo Absoluto, Doutor Destino, Justiceiro ou Wolverine.
- [ ] Não misturar edições só porque aparecem em uma categoria/editoria compartilhada.
- [ ] O gênero/filtro de cada série identifica a editora (DC Comics, Marvel Comics, Image Comics, Dynamite Entertainment, IDW Publishing ou Mangás), evitando entradas sem editora em "Outros".

## Séries prioritárias — conferir capítulos em ordem crescente

- [ ] Absolute Batman: #1 a #23, incluindo #21, #22 e #23 publicados como "Batman Absoluto".
- [ ] Batman: Padrões Sombrios: #1 a #12, separado de Absolute Batman.
- [ ] Flashpoint: #0 a #5, separado de Flash Absoluto.
- [ ] Flash Absoluto: #1 a #12.
- [ ] Lanterna Verde Absoluto: #1 a #17, sem misturar Lanterna Verde (2023).
- [ ] Lanterna Verde (2023): #1 a #9.
- [ ] The Boys: #1 a #44; a segunda página do arquivo contém #31 a #44.
- [ ] Justiceiro (2022): #1 a #12.
- [ ] O Justiceiro (2026): #1 a #6, separado da fase de 2022.
- [ ] Guerra Contra Destino: #1 a #6, separado de Um Mundo nas Mãos do Destino #1 a #3.
- [ ] Deadpool e Wolverine: #1 a #7; não importar Absolute Batman #5 que aparece indevidamente em categorias Marvel.
- [ ] Homem-Aranha 2099: #1.
- [ ] Invencível: #1 a #16 (e #0 se listado na categoria).
- [ ] Savage Dragon: #1 a #9.
- [ ] The Walking Dead: volumes 1 a 4.
- [ ] Dungeons & Dragons: #0 a #5.
- [ ] Caverna do Dragão: Aventuras de Sábado pela Manhã: #1 a #4.
- [ ] Zetman: volumes 1 e 2.
- [ ] CDZ – Saint Seiya: volumes 1 e 2.

## Leitura

- [ ] Cada capítulo abre a página de leitura da edição correspondente, não uma página de outra HQ.
- [ ] A página do leitor carrega todas as imagens em ordem.
- [ ] Não confundir links "Veja também", navegação, breadcrumbs ou downloads com capítulos.
- [ ] Edições com leitor online ausente não recebem capítulo inventado.
- [ ] Capítulos aparecem como "Capítulo 1", "Capítulo 2", etc., sequencialmente após ordenar as edições reais.

## Busca e atualização

- [ ] Busca por título retorna a edição correta.
- [ ] Atualizar catálogo não cria duplicatas.
- [ ] Conferir todas as páginas numéricas dos arquivos (não apenas a primeira).
- [ ] Conferir categorias agregadoras com títulos de várias séries.

## Publicação

- [ ] Build release e lint concluem com sucesso.
- [ ] Incrementar versionCode para que o Tachimanga reconheça a atualização.
- [ ] Gerar APK/JAR e publicar o índice compatível com o Tachimanga.
- [ ] Instalar em uma instalação limpa e validar no aplicativo.
